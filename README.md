# Sports Pack

A pack of small, single-file sports games and live wallpapers (HTML5 Canvas, no dependencies). **Each sport lives in its own folder** so they never get mixed up.

| Sport | Folder | What's in it |
|---|---|---|
| Ice hockey | [`hockey/`](hockey/) | [`game.html`](hockey/game.html) – playable arcade game · [`wallpaper/`](hockey/wallpaper/) – CPU-vs-CPU live wallpaper |
| Mini golf | [`golf/`](golf/) | [`index.html`](golf/index.html) – two CPU golfers play a 9-hole match (you can take shots too) · [`windows/`](golf/windows/) – desktop-wallpaper launcher |

Windows desktop wallpapers need nothing but PowerShell and Edge (both built in) – see each sport's README:
[`hockey/wallpaper/README.md`](hockey/wallpaper/README.md) · [`golf/README.md`](golf/README.md).

[`examples/`](examples/) holds unrelated sample wallpapers.

# Arcade Ice Hockey

A lightweight, single-file arcade ice hockey game built with HTML5 Canvas and Web Audio — plus a live-wallpaper edition for Windows and Linux.

- [`examples/arcade_ice_hockey.html`](examples/arcade_ice_hockey.html) — the playable game (mouse or WASD/arrows, Space/click for a Slapshot Dash). Open it in a browser.
- [`wallpaper/`](wallpaper/) — CPU-vs-CPU live wallpaper, fully offline. See [`wallpaper/README.md`](wallpaper/README.md) for Lively Wallpaper, Wallpaper Engine and Linux setup.

# Arcade Ice Hockey

- [`game.html`](game.html) – the playable game. Move with the mouse or WASD/arrows; click or Space for a Slapshot Dash. (Loads Tailwind and Google Fonts from a CDN, so it needs an internet connection for styling.)
- [`wallpaper/`](wallpaper/) – CPU-vs-CPU live wallpaper, fully offline. Setup for Windows (no extra software) and Linux: [`wallpaper/README.md`](wallpaper/README.md).
